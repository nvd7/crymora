# Design

Esta pasta guarda a identidade visual do Crymora e o histórico de exploração da interface.

## Logo

- `logo/logo-transparent.png` — versão com fundo transparente usada no app, no README e no site.
- `logo/logo-original.jpg` — referência original da marca.
- `logo/preview-dark.png` e `logo/preview-light.png` — conferência de contraste nos dois temas.
- `logo/sizes-dark.png` e `logo/sizes-light.png` — teste de legibilidade em tamanhos pequenos.
- `logo/test-a.png`, `logo/test-b.png`, `logo/test-c.png` — estudos descartados.
- `logo/whitemap.png` — máscara auxiliar usada na geração do ícone.

## Mockups

`mockups/` contém as explorações iniciais de UI em HTML e os screenshots correspondentes. Eles **não fazem parte do aplicativo** e não são carregados pelo Tauri; ficam aqui apenas como registro do processo de design.

A interface em produção está em `ui/`.
